Open source · AGPL-3.0

Private messaging you can run on a spare phone.

Hush Relay is an end-to-end encrypted messenger with no accounts, no phone numbers and no app store. The server is one PHP file that only ever holds sealed envelopes.

Experimental: not yet independently audited
Sender's device
Locks it

Double Ratchet encryption. A new key for every message.

Relay (your phone)
Holds it

Sees a mailbox number and a sealed blob. Not the words. Not the sender.

Recipient, anywhere
Unlocks it

Picks it up live in under a second, then the relay deletes it.

Protected

  • Message content, end to end
  • Who sent each message (sealed sender)
  • Past messages if a device is stolen
  • Exact message length (padded)

Still visible to the relay host

  • IP addresses and timing
  • Which mailbox received mail
  • Roughly how big each message is
  • Whether the relay is up at all
