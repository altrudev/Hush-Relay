# Hush Relay brand assets

Logo, icons and promotional images for Hush Relay.

Copyright © 2026 Valentyn Rukhaylo (ALTRU.dev). The images in this folder identify the original project.

| File | Use |
|---|---|
| `logo-mark.svg`, `logo-mark-512.png`, `logo-mark-1024.png` | App icon and logo mark (rounded tile) |
| `logo-mark-flat.svg` | Full-bleed square, for platforms that round icons themselves |
| `logo-mark-inverse.svg` | White tile, for teal or dark backgrounds |
| `logo-horizontal.png` | Mark with the wordmark, transparent background |
| `banner.png` | README header (1600×480) |
| `social-preview.png` | GitHub social preview and link cards (1280×640) |
| `install-and-use.png` | Install and use guide (1080×1350) |
| `render.py` | Regenerates the PNG images from HTML (Playwright, Chromium, Inter font) |

**Colours:** teal `#0e7a68` (primary), deep teal `#0a5c4f`, mint `#e3f2ee`, ink `#122029`, muted `#5a6773`, background `#f3f6f8`.
**Type:** Inter and Inter Display.
